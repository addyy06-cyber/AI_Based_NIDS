Cross-Dataset Evaluation

Purpose: Results from cross-validation on CICIDS2017 describe performance on the network the model was trained on. To measure generalisation, the final model (Random Forest, 100 trees, minimum leaf size 5, square-root class weights, trained on all of CICIDS2017 and not modified afterwards) was applied to a second dataset, CSE-CIC-IDS-2018.

Data and mapping: Six daily files of the processed CSE-CIC-IDS-2018 traffic were used (6,269,924 flows after removing rows with missing, infinite or invalid values; duplicates kept). Every one of the model's 69 features has a counterpart column under a different name, and units were checked (flow durations have the same scale in both datasets). Labels were mapped to the model's classes (for example, HOIC and LOIC-UDP to DDoS; FTP-BruteForce to FTP-Patator; the three web attacks to Web Attack). PortScan does not occur in these files, and the model has no class for Infiltration, so neither could be tested. Each file contains exactly 1,048,575 rows, which suggests it was truncated at the spreadsheet row limit.

Overall, the model reached a macro-F1 of 0.24 and flagged 2.7% of attack flows as attacks, while raising false alarms on 0.03% of benign flows. Accuracy was 0.69, which is misleading because 68% of the flows are benign. Only DoS slowloris was detected reliably (recall 0.98, precision 0.95); DoS GoldenEye was partly detected (recall 0.35); DoS Hulk (0.04), SSH-Patator (0.01) and Web Attack (0.09) were mostly missed, and DDoS, Bot, FTP-Patator and DoS Slowhttptest were not detected at all. When the model did raise an alert for Hulk, SSH-Patator or slowloris, it was usually correct (precision 0.95 to 0.98). On most missed attack flows the forest voted strongly for BENIGN (median vote 0.89 to 0.96, similar to the 0.975 for truly benign flows), so adjusting the decision threshold would not recover them.

Diagnosis: A random forest trained to distinguish benign flows of the two datasets achieved an AUC of 0.9996 (0.9988 after removing its five most informative features), showing a large and widespread dataset shift. The most discriminative features included the minimum forward segment size, the forward and backward header lengths and the destination port, which depend on protocol settings and network configuration rather than on malicious behaviour. For DDoS and DoS Hulk, the typical 2018 attack flow carries no payload in either direction, unlike the corresponding CICIDS2017 flows. For SSH-Patator, the median values of the model's eight most important features were close to the CICIDS2017 attack on all eight, yet recall was 1.3%, which is consistent with the model relying on environment-specific features. These diagnostics are descriptive and do not isolate a single cause; differences in network, extraction tool version, attack tooling, flow assembly and labelling are all possible.

Limitations of this experiment: Files appear truncated; labelling errors are reported for both datasets [cite]; the label mapping is a judgement; Web Attack has only 362 flows; the feature comparison used medians of eight features and samples; and this is a single evaluation without confidence intervals.

Conclusion: The macro-F1 of about 0.95 obtained within CICIDS2017 should not be read as evidence that the model generalises to other networks. Training on several datasets, removing environment-specific features, and evaluating on held-out days are the natural next steps.
